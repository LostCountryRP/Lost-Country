# 🗺️ Luoghi della Lore

Questa sezione raccoglie città, territori, edifici e luoghi di interesse legati agli eventi narrativi di **Lost Country V1**.

Ogni luogo potrà avere una propria scheda con:
- descrizione;
- eventi collegati;
- personaggi coinvolti;
- indizi scoperti;
- stato attuale nella Lore.
